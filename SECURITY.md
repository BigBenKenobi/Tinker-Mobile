# Reporting security problems

Do not post tokens, pairing QR contents, recovery databases or private domain data
in public issues. Use GitHub's private vulnerability reporting if it is enabled;
otherwise contact the repository owner privately before sharing sensitive details.
Public issues can describe a problem without disclosing secrets or exploit data.

Supported review work targets native iOS 17+ and protocol 2/schema 5. No hosted
account or public sync endpoint is supported. A CI pass is not a security audit.
